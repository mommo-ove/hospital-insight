# 架构与接口

## 一次提问的完整路径

1. React 提交用户问题和会话 ID。
2. 服务读取上一次成功查询的结构化条件；若上一轮在澄清，则合并用户补充。
3. 明确不支持的请求由本地边界规则返回。云端模式调用兼容模型接口，演示模式使用规则解析器。
4. 模型只能返回 `Decision`：查询、澄清或不支持。查询必须符合 Pydantic `QueryPlan`，未知字段被拒绝，非法模型输出最多修复一次。
5. 查询引擎核查科室、时间、聚合规则和比较覆盖率。SQLAlchemy 从固定字段和表达式生成参数化 SELECT。
6. 用 SQLite 只读连接在同一个读事务内计算并收集来源。金额整数分求和，比例用 Decimal 计算，最后转换展示单位。
7. 本地模板生成文字、图表配置和结果表。保存查询条件、结果、SQL、来源单元格与版本快照，支持历史恢复与 CSV 导出。

第一版不执行模型生成的 SQL 或 Python；数据只有一张结构固定的小表，无需向量数据库、训练或任意代码工具。

## 后端职责

- `catalog`：18 项经营指标、22 个源表头、别名及允许的聚合方式。
- `importer`：文件限制、表头映射、值校验、对账、预览、版本化提交。
- `schemas`：结构化查询意图，限定指标、维度、操作符、排序、比较及展示单位。
- `query`：科室筛选、聚合合法性、参数化 SQL、本期与对比期、来源和展示。
- `parser` / `llm`：相同 Decision 接口的离线规则与云端适配器。
- `service`：会话、澄清、多轮条件及失败状态保存。
- `main`：FastAPI、上传与导出、静态前端、启动时初始导入。

## 数据存储

- `department_monthly`：科室月度记录，以年月＋科室唯一；金额为整数分；来源 JSON 包含原始值、列映射、文件 SHA-256 和版本。
- `imports`：预览快照、校验统计、基础版本、提交状态和提交版本。校验失败不改变事实表。
- `state`：单调数据版本。写事务使用 `BEGIN IMMEDIATE`；提交检查基础版本，防止过期预览覆盖新数据。
- `conversations`：标题、上一次成功条件、待澄清条件。
- `messages`：用户问题与完整响应快照。数据更正后旧答案仍对应当时版本。

## 公共 API

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| GET `/api/health` | 无 | 模式、模型名称、配置是否齐全；不含密钥 |
| GET `/api/catalog` | 无 | 指标、科室、类型、别名、年月范围、版本 |
| POST `/api/imports/preview` | multipart `file` | 新增/重复/冲突/错误、样例、预览ID |
| POST `/api/imports/{id}/commit` | `{overwrite_conflicts: boolean}` | 提交状态与数据版本 |
| GET `/api/imports` | 无 | 最近50次导入记录 |
| POST `/api/chat` | `{question, conversation_id?: string}` | 统一聊天响应 |
| GET `/api/conversations` | 无 | 最近100个会话摘要 |
| GET `/api/conversations/{id}` | 无 | 会话完整消息快照 |
| GET `/api/queries/{id}/export` | 无 | UTF-8 BOM CSV，文本防公式注入 |

响应状态为 `success / clarification / no_data / unsupported / error`。公共字段为 `id, conversation_id, question, answer, plan, rows, columns, chart, sources, sql, warnings, choices, mode, model`。成功结果还提供版本、实际范围、口径说明。

## 默认限制与解释

- 单次最多5项指标、5个数值条件、100组展示结果。数值条件作用于聚合结果。
- 环比支持单月与前一月；同比支持一个时间区间与上年相同区间。第一版不支持“每月同比曲线”，会提示选择一个区间。
- 结果排序与截断在本地发生，出处只保留展示分组对应的输入行。SQL 面板明确说明这一步。
- 趋势不插值，没有数据的月份不补造金额；不完整范围给出告警。平均住院日等只允许每组一条源记录。
- SQLite 适合当前单用户规模。云端 API 调用异步；服务不包含医院生产部署所需的认证授权。
- 云端可能语义理解错误，因此真实模型需用固定题库及实际场景验收。JSON 合法、SQL 可执行不等于问法理解正确。

## 隐私边界

只有模型适配器发起外部请求，其输入函数只接受问题、允许的目录元数据、日期和上一轮 QueryPlan。不会接收原始行、完整聊天结果或导入对象。模型响应解析失败时只回传该模型的无效文本用于一次修复。对模型服务错误只展示状态码或通用提示，不回显服务商错误体或请求头。

原始 Excel 和所有导入/会话数据留在本机。`.env`及数据库列入 `.gitignore`。原始Excel随私有仓库和镜像分发，首次启动自动导入；发布仓库或镜像前需考虑所附数据的可见范围。
