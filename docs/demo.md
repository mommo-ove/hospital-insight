# 五分钟演示脚本

1. 运行 `start.ps1`，访问首页，指出数据覆盖 2024-01 至 2026-04、8 个科室、224 条记录。顶部会明确显示当前为离线演示还是云端模型。
2. 提问 `2025年心内科总收入是多少？`，展示 25,979,271 元。打开“查看依据”，查看 Excel 行号、金额单元格和 SQL 参数。
3. 追问 `那儿科呢？`，说明时间与指标沿用，科室切换。刷新页面后从左侧最近对话恢复记录。
4. 新建对话，提问 `2026年4月各科室收入从高到低排名`，展示柱状图，再切换结果表并导出 CSV。
5. 新建对话，提问 `2025年心内科每月收入走势，按万元展示`，展示折线图和万元单位。
6. 提问 `2025年心内科花费多少钱？`，选择“合计收入”；再演示 `做一次CT多少钱？`，说明没有项目价格时系统不会编造。
7. 打开“数据管理”，上传原始 Excel，预览应显示 224 条重复、0 条新增、0 条冲突。点击“确认导入”，记录数保持不变。
8. 打开“指标说明”，查看医保占比的汇总口径以及床位、平均住院天数、次均费用的限制。

真实云端模型演示前，先执行80题云端评测并查看报告。离线题库通过不能作为云端效果证明。
